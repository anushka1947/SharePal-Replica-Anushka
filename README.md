SharePal – Website Replica

ABOUT THE PROJECT

I developed this project to recreate the look and feel of the SharePal website. The goal was to build a clean, user-friendly interface where users can explore rental products and navigate between different categories.

I worked on the website layout, header, navigation, product sections, and rental date selection interface. I also debugged and refined the implementation to improve the visual consistency and user experience.

TECHNOLOGIES USED

React, TypeScript, CSS, and AI-assisted development tools.
